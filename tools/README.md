# TorrServer для сборки установщика

Положите сюда `TorrServer.exe` перед сборкой установщика:

```
tools/torrserver/TorrServer.exe
```

Скачать MatriX.150:

- <https://github.com/YouROK/TorrServer/releases/tag/MatriX.150>
- файл `TorrServer-windows-amd64.exe`

Если файла нет, установщик соберётся без TorrServer, а приложение попробует
скачать его при первом запуске.
